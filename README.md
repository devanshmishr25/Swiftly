# Swiftly ⚡
**The Ultimate On-Demand Multi-Role Marketplace (MERN Stack)**

Swiftly is a high-performance, aesthetically-driven platform that connects customers with verified professionals across various service categories.

## ✨ Key Features
- **Multi-Role Ecosystem:** Separate workflows for Customers, Providers, and Super Admins.
- **Provider Approval Guard:** Super Admin dashboard for verifying and approving new joinings.
- **Real-Time Search:** Category-based professional discovery with instant results.
- **Modern Dashboard:** Fluid UX with Glassmorphism and dark/light mode synchronization.
- **Responsive Design:** Reengineered layout that fits perfectly on every screen size.

## 🛠️ Technology Stack
- **Frontend:** React, Vite, Lucide Icons, Vanilla CSS (Premium Custom Styles)
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas (Mongoose ODM)
- **Auth:** JWT-based secure session management

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/devanshmishr25/Swiftly.git
cd Swiftly
```

### 2. Setup Backend
```bash
cd backend
npm install
# Create a .env file and add your MONGO_URI and JWT_SECRET
npm start
```

### 3. Setup Frontend
```bash
cd ../frontend
npm install
npm run dev
```
